# Hosted synthetic worker experiment

This private-IPC example is a synthetic proof of concept, not a server or a
security boundary. It uses Loomem's local ONNX embedder, RocksDB, Tantivy,
vector search and hybrid scoring. It does not implement Hosted authorization,
publication, journal, recovery, OS process isolation, encryption, sanitization,
or the complete ingest pipeline. Never expose it to clients or real data.

Build with `cargo build -p loomem-core --example hosted_poc_worker`. Start the
binary with `ROOT CONFIG MODEL_DIR`; ROOT must be an existing private directory,
CONFIG an unmodified compatible Loomem TOML, and MODEL_DIR a local 384-dimension
model directory containing `model.onnx` and `tokenizer.json`. One worker is
assigned to one synthetic scope and communicates over private stdin/stdout with
one JSON object per line. The supervisor must use a clean environment without credentials (including
`LOOMEM_AT_REST_MASTER_KEY`) and enforce all filesystem and process boundaries. In particular, `search` and `read` open Loomem's original mutable
storage adapters: use them only on disposable physical copies of a previously
fenced generation, never on the authoritative immutable generation. A marker
is only a completeness check, not an authorization or fencing mechanism.

Requests:

* `{"cmd":"prepare","op_id":"op1","generation":"g1","content":"synthetic text"}`
  returns `ok`, `op_id`, `generation` and the model's `embedding`.
* `{"cmd":"build","generation":"g1","records":[{"op_id":"op1","id":"m1","content":"synthetic text","embedding":[...]}]}`
  creates a fresh staging directory and returns `ok`, `generation`, `count`.
  The caller supplies the complete journal-derived set. Optional `failpoint`
  `after_rocksdb` fails the request, while `after_rocksdb_abort` abruptly
  terminates the process. `after_rocksdb_wait` emits the fixed stderr line
  `LOOMEM_POC_BARRIER_AFTER_ROCKSDB` and parks until the supervisor sends
  SIGKILL, allowing deterministic crash injection. No ready marker is written.
* `{"cmd":"search","generation":"g1","query":"synthetic","embedding":[...]}`
  returns separate `vector`, `bm25`, and Loomem `hybrid` results; embedding
  must be generated by `prepare`. Empty vector results are not silently
  interpreted as successful vector retrieval.
* `{"cmd":"read","generation":"g1","id":"m1"}` returns `chunk` or null.
* `{"cmd":"shutdown"}` exits cleanly.

Failures return `{"ok":false,"error":"operation failed"}`; a terminated or
timed-out process has an uncertain outcome. The caller must reconcile against
its canonical journal and may not blindly retry a generation name. Hosted must
prevent access to partial staging before recovery. All generation and record
identifiers are bounded ASCII letters, digits, underscore, or hyphen.
