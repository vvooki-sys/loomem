Czym jest Twój kontekst

Nie kolejny RAG. Twój kontekst.

Loomem nie gromadzi plików ani nie przeszukuje ogromnych repozytoriów danych w poszukiwaniu fragmentu do wklejenia. Przechowuje to, co naprawdę tworzy kontekst, i działa dyskretnie w tle jako warstwa wspierająca Twoją pracę z AI.

✗ Czego nie robimy

Nie zbieramy Twoich plików ani nie indeksujemy rozległych zbiorów dokumentów. Nie każemy Ci wszystkiego wyjaśniać od nowa, żeby potem wypełnić prompt całym korpusem i liczyć na właściwy fragment.

✓ Co zachowujemy

Fakty, osoby, miejsca, projekty, wybory i chronologię, które tworzą kontekst dla trafniejszych decyzji. Dzięki temu agenci i modele mogą Cię lepiej poznać i pamiętać Twoje preferencje.

Możliwości

Twój kontekst, gotowy dla dowolnego modelu

Loomem zachowuje wartościowy kontekst i udostępnia go narzędziu lub modelowi, którego używasz, dzięki szybkiemu wyszukiwaniu hybrydowemu. Model możesz zmienić; kontekst pozostaje Twój.

Znajdź właściwy kontekst

BM25 (Tantivy), embeddingi wektorowe i sygnały z grafu encji są łączone za pomocą ważonego wyniku hybrydowego (wektor 0,6 / BM25 0,4), aby trafny kontekst pojawiał się pierwszy.

Kontekst, który zachowuje porządek

Procesy w tle łączą powiązane fakty, rozwiązują sprzeczności i wygaszają nieaktualny kontekst. To „sen”, dzięki któremu kontekst staje się z czasem bardziej precyzyjny.

Kontekst w czasie

Każdy fakt ma zarówno czas zapisania, jak i czas zdarzenia, więc „co wiedziałem w marcu” różni się od „co wydarzyło się w marcu”. Kontekst pamięta nie tylko co, ale i kiedy.

Uporządkowany kontekst

Osoby, projekty i narzędzia są połączone w graf z aliasami i relacjami, co ułatwia dokładniejsze wyszukiwanie i odkrywanie powiązań.

Podąża za Tobą

Obsługuje MCP przez standardowy HTTP oraz rejestrację klienta OAuth. Twój kontekst połączysz z Claude, ChatGPT, Cursor lub własnym agentem.

Twój kontekst, Twoje klucze

Opcjonalne szyfrowanie kopertowe AES-GCM na poziomie pól, z kluczem głównym przekazywanym przez środowisko. Kontrolujesz także prywatność swojego kontekstu.

Status: wczesny etap

Silnik jest już używany codziennie, ale publiczny interfejs API i format przechowywania mogą się jeszcze zmienić. Możliwe są niedoskonałości — zgłoszenia i PR-y są mile widziane.

Pętla snu — kontekst, który sam się porządkuje

Loomem nie tylko zapisuje i odczytuje. Procesy w tle z czasem porządkują kontekst, tak jak sen konsoliduje wiedzę zdobytą w ciągu dnia. Kontekst staje się precyzyjniejszy bez Twojej dodatkowej pracy.

01

Przyjmowanie

Surowe zdarzenia są zapisywane jako fragmenty L0. Nowe fakty są porównywane z istniejącymi — sprzeczności są oznaczane i wersjonowane, a nie po cichu nadpisywane.

przy zapisie
02

Konsolidacja

Powiązane fragmenty L0 są grupowane tematycznie i kompresowane przez LLM do obserwacji L1, z których każda wskazuje na swoje źródła.

co 5 min
03

Sen i wygaszanie

Fakty wygasają według krzywej inspirowanej ACT-R. Używane informacje wygasają wolniej, a dawno niewykorzystywane przechodzą w stan uśpienia. Zapominanie jest funkcją systemu.

co godzinę
04

Kojarzenie

Grupowanie faktów L1 ujawnia nieoczywiste związki między osobami, projektami i decyzjami, których nie da się łatwo odkryć w płaskiej strukturze.

co 6 godz.

Szybki start

Od instalacji do asystenta, który pamięta

Na macOS lub Linuksie. Wykonaj kolejno poniższe kroki.

1

Zainstaluj pliki wykonywalne

Bez sudo; instalacja w ~/.loomem.

# gotowe pliki wykonywalne, macOS i Linux
curl -fsSL https://raw.githubusercontent.com/vvooki-sys/loomem/main/install.sh | sh
2

Dodaj ~/.loomem/bin do PATH

Instalator również wyświetli tę instrukcję.

echo 'export PATH="$HOME/.loomem/bin:$PATH"' >> ~/.zshrc # lub ~/.bashrc
exec $SHELL
3

Pobierz model i uruchom serwer

Instalator przygotowuje konfigurację w ~/.loomem, ale lokalny model embeddingów trzeba pobrać osobno, także w trybie bez klucza. Aby używać domyślnych funkcji opartych na LLM, zastąp tekst zastępczy swoim kluczem API OpenAI:

curl -fsSL https://raw.githubusercontent.com/vvooki-sys/loomem/main/scripts/fetch-embedding-model.sh | sh
export OPENAI_API_KEY="YOUR_OPENAI_API_KEY"
cd ~/.loomem && loomem-server

Aby uruchomić bez klucza LLM, zamiast niego ustaw export LOOMEM_ALLOW_KEYLESS=1. memory_store i wyszukiwanie działają, ale ekstrakcja LLM i proces „snu” są niedostępne. memory_ingest może nadal zapisać oczyszczone źródło, zanim zwróci błąd ekstrakcji.

4

Sprawdź, czy działa

W drugim terminalu. Instalator domyślnie używa portu 3030 i zapyta o inny, jeśli jest zajęty (ustaw LOOMEM_PORT aby pominąć pytanie). Jeśli port został zmieniony, użyj właściwego.

curl http://localhost:3030/health
# {"status":"ok","version":"0.5.4"}
5

Połącz Claude Code

Dodaj serwer MCP przez streamable HTTP.

claude mcp add --transport http loomem http://localhost:3030/mcp

Używasz aplikacji desktopowej Claude lub Cowork? Korzysta ona ze stdio zamiast HTTP — dodaj most w pliku claude_desktop_config.json, a następnie uruchom Claude ponownie. Most natywny, bez Node.js (Loomem ≥ v0.2.1):

"loomem": {
  "command": "/…/.loomem/bin/loomem-cli",
  "args": ["mcp-stdio", "--url", "http://127.0.0.1:3030"]
}

Lub z Node.js: "command": "npx", "args": ["-y", "mcp-remote", "http://127.0.0.1:3030/mcp", "--allow-http"].

6

Wypróbuj

W Claude: „Zapamiętaj, że we wszystkich narzędziach preferuję tryb ciemny”. Następnie w nowej rozmowie: „Co wiesz o moich preferencjach?” — odpowiedź pochodzi z Loomem.

Połącz klienta

Obsługuje MCP przez streamable HTTP

Loomem nasłuchuje pod adresem /mcp. Działa z każdym klientem MCP — poniżej instrukcje dla popularnych narzędzi. Jedna instancja może obsługiwać kilku klientów jednocześnie; korzystają z tego samego kontekstu.

Claude Code

claude mcp add --transport http loomem http://localhost:3030/mcp

Aplikacja Claude na komputer i Cowork

Aplikacja komputerowa łączy się z lokalnymi serwerami przez stdio, a pole własnego konektora przyjmuje tylko https:// — dlatego http://localhost nie można tam wkleić. Dodaj most w pliku claude_desktop_config.json, a następnie uruchom Claude ponownie. Most natywny, bez Node.js (Loomem ≥ v0.2.1):

"loomem": {
  "command": "/…/.loomem/bin/loomem-cli",
  "args": ["mcp-stdio", "--url",
    "http://127.0.0.1:3030"]
}

Alternatywnie, z Node.js użyj uniwersalnego mcp-remote rozwiązania: "command": "npx", "args": ["-y", "mcp-remote", "http://127.0.0.1:3030/mcp", "--allow-http"]. Uruchamiasz Loomem na innym komputerze? Zabezpiecz go przez TLS, ustaw SERVER_ORIGINi dodaj zdalny konektor https://your-domain/mcp .

ChatGPT

ChatGPT w przeglądarce, tryb deweloperski (Pro/Plus = tylko odczyt; Business/Enterprise/Edu = odczyt i zapis). Udostępnij przez HTTPS, ustawiając SERVER_ORIGIN , włącz tryb deweloperski w Settings → Apps → Advanced Settings, następnie w Settings → Apps → Create wklej adres /mcp , wybierz OAuth i uruchom Scan Tools.

OpenClaw

openclaw mcp add loomem \
  --url http://localhost:3030/mcp \
  --transport http

Pozostań przy połączeniu lokalnym, chyba że używasz TLS

Uwierzytelnianie jest domyślnie wyłączone przy użyciu lokalnym. Zachowaj adres nasłuchiwania 127.0.0.1 , chyba że używasz TLS i uwierzytelniania. Nigdy nie wystawiaj niezabezpieczonego portu HTTP do internetu.

FAQ

Odpowiedzi na pytania

Czym jest Loomem?

Loomem to otwartoźródłowa warstwa kontekstu dla agentów LLM. To pojedynczy program w Rust, oparty na RocksDB i Tantivy oraz dostępny przez Model Context Protocol (MCP). Udostępnia Claude, ChatGPT, Codex i innym klientom MCP fakty, decyzje i historię potrzebne w pracy. Kontekst jest przenośny, lokalny i należy do Ciebie.

Czym Loomem różni się od mem0, Zep, Letta i cognee?

Loomem działa jako pojedynczy program w Rust bez usług zewnętrznych; większość alternatyw wymaga osobnej bazy wektorowej lub grafowej. Stawia na własność i przenośność kontekstu, działa lokalnie na Twojej infrastrukturze, obsługuje embeddingi offline przez modele ONNX i ma wbudowaną obsługę MCP. Zobacz pełne porównanie →

Czy Loomem jest bezpłatny i otwartoźródłowy?

Tak. Loomem jest dostępny na licencji Apache-2.0 i można go bezpłatnie hostować samodzielnie. Kod źródłowy jest na GitHub.

Czy Loomem wymaga internetu lub OpenAI?

Podstawowe użycie nie wymaga internetu. Embeddingi mogą działać lokalnie za pomocą modelu ONNX, a zapis i wyszukiwanie kontekstu działają offline. Klucz API OpenAI jest potrzebny do etapów opartych na LLM (ekstrakcji memory_ingest, konsolidacji, snu i wykrywania sprzeczności). Bez niego są one niedostępne, a domyślna konfiguracja uruchamia się tylko z LOOMEM_ALLOW_KEYLESS=1; memory_store i wyszukiwanie nadal działają.

Jakich klientów LLM można połączyć z Loomem?

Dowolnego klienta obsługującego MCP. Loomem używa MCP przez streamable HTTP i udostępnia instrukcje dla Claude, Claude Code, ChatGPT, Codex i Cursor oraz dynamiczną rejestrację klienta OAuth dla zdalnych konektorów.

Dlaczego nie korzystać wyłącznie z pamięci ChatGPT lub Claude?

Wbudowana pamięć jest związana z jednym dostawcą. Loomem pozwala przenosić własny kontekst między narzędziami i modelami oraz hostować go samodzielnie. Udostępnia uporządkowany graf encji i historię w dwóch wymiarach czasu.
